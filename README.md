# Desafio QI Tech - Banco RNV

Repositório da aplicação para o desafio do Bootcamp QI Tech

Por enquanto, pra rodar os containers no modo desenvolvimento:

docker compose up

Dá pra verificar o status da criação das tabelas pelo log do container e se quiser conectar ao banco usando o dbeaver só utilizar as credenciasis que estão em no docker-compose.yml
